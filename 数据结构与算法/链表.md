### 第四节 线性表的链式表示

数组在内存中的存储是连续而大块的，这会导致内存碎片率的提高。在数组过于巨大时，某个内存池预分配的内存块可能存不下这个连续数组。这时为了减轻它的压力，就可以选择使用链表。他可以在任意区域存储，并通过指针链接，就和拴在一起的铁链子一样。但同时也会失去随机存取的特性。

#### 单链表的定义

**单向的链式线性表称为单链表。** 它除了一个自身的值之外，还需要一个指向后面那个元素的指针。通过不停的链接形成。他们不需要连续存储，可以分散在内存各处。在寻找中间的元素时，因为不是连续存储，所以需要遍历所有节点。

#### 单链表的结构

链表的第一个元素为头节点，最后一个元素为尾节点。
**单链表的特性如下：**
* 结构如[元素值]-[指向下一节点的指针]，尾节点一般指向nullptr(在C++中)。
* 当头指针内容为null时，这个表为空表。
* 当存在头节点时，头指针指向头节点。当不存在头节点时，头指针指向第一个数据值节点。
* 链表比数组占用更多空间，因为多了引用。

**带头节点的优点如下：**
* 若无头结点，空表的头指针指向空域，也就是null。有头节点的话，空表的头指针指向的首先是非null域，然后再是null。可以统一两者。
* 有头结点的情况下，真正有数据的节点其实在第二个上，这样就不用在第一个元素上特殊处理了。

以下是链表结构的结构体：
```c++
struct ListNode {
    int val;         // 节点值
    ListNode *next;  // 指向下一节点的指针
    ListNode(int x) : val(x), next(nullptr) {}  
};
```

##### 初始化链表

// 初始化各个节点
ListNode* n0 = new ListNode(1);

ListNode* n2 = new ListNode(2);
ListNode* n3 = new ListNode(5);

// 构建节点之间的引用
n0->next = n1;
n1->next = n2;
n2->next = n3;

###### 指向和指针运算

指针运算中，(\*p)指p节点本身，那么(\*p).data就为p节点的数据指针。它的' . '左边需要一个结构体变量，而不是指针，所以需要使用' \* '来让指针域转为变量，并通过' . ’访问内部数据。同理，关于\*p的下一节点指针域便是(\*p).next；关于\*p的下一节点数据域便是(\*(\*p).next).data。

指向运算刚好相反，它的' -> '左边需要一个结构体指针，而不是变量。p->data已经可以表示p节点的数据域。同理，关于p的下一结点指针域便是p->next；下一节点数据域便是p->next->data。
